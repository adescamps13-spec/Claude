# Storylines

1. **Built: "Isometric world, one continuous trip"** (object chain + flight through worlds). Every scene enters through an object
   from the previous one: charger screen -> coins -> tiles that become a city -> card that flips -> grid -> route -> tap -> station -> mark.
   Picked because it carries all 6 messages of the source material in 30 s while staying one story (a charge, a trip).
2. "Battery 5% -> 100%" (one number carries the film): one battery gauge crosses every scene and fills up with each feature,
   ending at 100% on the logo. More linear, fewer worlds.
3. "Type-led" (kinetic type cut on the beat): giant brand words (ÉCONOMIQUE, RAPIDE, PARTOUT, EN DIRECT) in colour fields,
   isometric objects as punctuation. Bolder, but less product.
